Visao Geral

O aplicativo foi criado para profissionais que precisam registrar informacoes e gerenciar demandas mesmo em locais sem conectividade com a internet. O app permite criacao, edicao e organizacao completa em modo offline com sincronizacao silenciosa em segundo plano.

O Desafio

Tratar resolucao de conflitos de versao entre alteracoes feitas no dispositivo e dados atualizados no servidor central sem exigir intervencoes manuais complexas do usuario.

A Solucao

Adocao do React Native com TypeScript e banco de dados SQLite local embarcado. Foi implementado o padrao CRDT (Conflict-Free Replicated Data Types) aliado a filas de eventos persistentes para sincronizacao assincrona confiavel.

Tecnologias Utilizadas

React Native TypeScript Expo SQLite Local Zustand Firebase Push

Principais Recursos

  • Funcionamento integral sem internet com persistencia local em SQLite.
  • Animacoes nativas fluidas a 120Hz com React Native Reanimated.
  • Notificacoes push inteligentes agendadas no proprio dispositivo.
  • Modo escuro e claro com deteccao automatica do sistema operacional.
