E-Commerce Store & Checkout

Plataforma de comercio eletronico completa com checkout transparente, calculo de frete e gestao de pedidos.

Funcao Fullstack Developer
Periodo 4 meses (2025)
Tipo Plataforma B2C
Status Producao
e-commerce-system.io

Visao Geral

O projeto consistiu no desenvolvimento de uma loja virtual orientada a performance e conversao de vendas. A aplicacao engloba desde a navegacao de catalogo com busca instantanea ate a finalizacao segura da compra com integracao de multiplos meios de pagamento.

O Desafio

Evitar perdas de pedidos decorrentes de abandono de carrinho gerado por lentidao no checkout e garantir a consistencia do estoque sob alto volume de requisicoes concorrentes durante eventos promocionais.

A Solucao

Adocao do Next.js com Server-Side Rendering (SSR) e Static Site Generation (SSG) para tempos de resposta inferiores a 300ms nas paginas de produtos. O backend utiliza transacoes atomicas no PostgreSQL com Prisma ORM e bloqueio otimista de estoque.

Tecnologias Utilizadas

Next.js 14 Node.js PostgreSQL Prisma ORM Stripe API Tailwind CSS Docker

Principais Recursos

  • Checkout seguro em uma etapa com suporte a cartao de credito, Pix e boleto.
  • Painel administrativo protegido para gestao de inventario, cupons e pedidos.
  • Carrinho persistente no cliente com sincronizacao em nuvem para usuarios autenticados.
  • Otimizacao SEO com metadados estruturados JSON-LD e pontuacao maxima no Google Lighthouse.
