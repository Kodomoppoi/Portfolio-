Visao Geral

Desenvolvido para atuar como ponto unico de entrada em uma arquitetura orientada a servicos, o Gateway e responsavel por autenticar requisicoes, aplicar politicas de limite de taxa (*rate limits*), validar esquemas e encaminhar chamadas para os microsservicos correspondentes.

O Desafio

Manter a latencia adicional introduzida pelo gateway abaixo de 4ms por chamada, mesmo sob trafego intenso com picos de dezenas de milhares de requisicoes por minuto.

A Solucao

Utilizacao de rotinas assincronas em Node.js com clusterizacao multithread e validacao de tokens criptograficos JWT em memoria. O controle de rate limiting foi implementado utilizando o algoritmo Token Bucket apoiado em instancias Redis em cluster.

Tecnologias Utilizadas

Node.js Express / Fastify Redis Cluster JSON Web Tokens (JWT) Docker Jest

Principais Recursos

  • Autenticacao distribuida sem estado (Stateless) com rotatividade de chaves.
  • Rate limiting parametrizavel por usuario, chave de API e endereco IP.
  • Logging estruturado com correlacao de requisicoes via Trace-ID.
  • Cobertura de testes automatizados unitarios e de carga com k6.
