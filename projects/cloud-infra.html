Cloud Infrastructure as Code

Automacao completa de infraestrutura em nuvem na AWS com Terraform, clusters Kubernetes gerenciados (EKS) e CI/CD.

Visao Geral

Projeto estruturado para eliminar processos manuais de configuracao de servidores e recursos de nuvem. Toda a topologia de rede, bancos de dados, clusters de computacao e politicas de seguranca sao definidos em codigo declarativo e versionados.

O Desafio

Garantir paridade exata entre os ambientes de Desenvolvimento, Homologacao e Producao, reduzindo os custos operacionais com recursos ociosos e mitigando falhas humanas durante publicacoes de novas versoes.

A Solucao

Criacao de modulos reutilizaveis em Terraform integrados com o GitHub Actions para execucao automatica de rotinas de validacao (*terraform plan*) e aplicacao (*terraform apply*) via pipelines auditaveis. Foi configurado auto-scaling de pods (HPA) no Kubernetes EKS.

Tecnologias Utilizadas

Amazon Web Services (AWS) Terraform Kubernetes (EKS) GitHub Actions Docker Prometheus & Grafana

Principais Recursos

  • Provisionamento de VPC com sub-redes publicas e privadas isoladas.
  • Politicas de seguranca com principio de menor privilegio via AWS IAM.
  • Monitoramento proativo de custos e utilizacao de instancias Spot para economia de ate 60%.
  • Deploy continuo automatizado sem indisponibilidade (*Zero Downtime Rolling Updates*).
